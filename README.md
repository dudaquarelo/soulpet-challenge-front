# 🐾 SoulPet
 
> Comunidade dentro da SoulUp para quem ama e cuida de pets.
 
---

## 📋 Descrição do Projeto
A SoulPet é uma plataforma web gamificada desenvolvida como parte do Challenge da FIAP, criada pela equipe InovaLab da turma 1TDSR-2026. A ideia é uma comunidade para tutores e amantes de pets dentro de um ecossistema chamado SoulUp.

---

## 🚀 Tecnologias Utilizadas

HTML5 — estrutura semântica das páginas
CSS3 — estilização, animações e efeitos visuais
JavaScript — interatividade e comportamento dinâmico
Responsive Design — adaptação para diferentes tamanhos de tela (mobile, tablet e desktop)
Flexbox — layout flexível e alinhamento de elementos
Git & GitHub — versionamento e hospedagem do código
